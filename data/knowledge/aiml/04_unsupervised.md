# Unsupervised learning
summary: Finding structure in data without labels: clusters, components and densities.
prereq: Mathematical foundations > Linear algebra

```definition
Unsupervised learning works with inputs x only, with no target y. Its goals are to group similar examples (clustering), to find a smaller set of directions that explain the data (dimensionality reduction), or to model how the data are distributed (density estimation).
```

## k-means clustering
summary: Partitioning data into k clusters by alternating assignment and centroid updates.

```definition
k-means splits the data into k clusters so that each point belongs to the cluster with the nearest centre (centroid), and the total squared distance from points to their centroids is as small as possible.
```

```formula
name: k-means objective
latex: J = \sum_{j=1}^{k} \sum_{\mathbf{x}_i \in C_j} \lVert \mathbf{x}_i - \boldsymbol{\mu}_j \rVert^2
text: The within-cluster sum of squares; each step of Lloyd's algorithm can only decrease it.
```

```steps
title: Lloyd's algorithm
1. Choose k initial centroids, for example with k-means++ seeding.
2. Assign every point to its nearest centroid.
3. Move each centroid to the mean of the points assigned to it.
4. Repeat steps 2 and 3 until the assignments stop changing.
```

```pitfall
k-means needs k in advance, finds only roughly spherical clusters of similar size, and can stop in a poor local minimum. Run it several times with different seeds and choose k with the elbow method or the silhouette score.
```

```formula
name: Silhouette score
latex: s(i) = \frac{b(i) - a(i)}{\max\{a(i), b(i)\}}
text: a(i) is the mean distance from point i to its own cluster and b(i) to the nearest other cluster; values near 1 mean well-separated clusters.
```

## Hierarchical clustering
summary: Building a tree of nested clusters by repeatedly merging or splitting groups.

```definition
Agglomerative hierarchical clustering starts with every point as its own cluster and repeatedly merges the two closest clusters until one remains. The result is a dendrogram, and cutting it at a chosen height gives a flat clustering with any number of clusters.
```

```compare
caption: Linkage criteria for merging clusters
Linkage, Distance between clusters, Tends to produce
Single, closest pair of points, long chain-like clusters
Complete, farthest pair of points, compact clusters of similar diameter
Average, mean of all pairwise distances, a compromise between single and complete
Ward, increase in within-cluster variance, compact clusters like k-means
```

## Gaussian mixture models and EM
summary: Soft clustering with a weighted sum of Gaussians fitted by expectation-maximisation.
prereq: Mathematical foundations > Probability and statistics

```definition
A Gaussian mixture model (GMM) assumes each point was generated by first picking one of K Gaussian components with probability pi_k and then sampling from that Gaussian. Unlike k-means, each point gets a soft membership probability for every cluster, and clusters can be elliptical.
```

```formula
name: Mixture density
latex: p(\mathbf{x}) = \sum_{k=1}^{K} \pi_k \, \mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_k, \Sigma_k), \qquad \sum_k \pi_k = 1
text: The density is a weighted sum of K Gaussian bumps.
```

```formula
name: E-step responsibilities
latex: \gamma_{ik} = \frac{\pi_k \, \mathcal{N}(\mathbf{x}_i \mid \boldsymbol{\mu}_k, \Sigma_k)}{\sum_{j} \pi_j \, \mathcal{N}(\mathbf{x}_i \mid \boldsymbol{\mu}_j, \Sigma_j)}
text: The probability that point i came from component k, given the current parameters.
```

```steps
title: Expectation-maximisation for a GMM
1. Initialise means, covariances and mixing weights, for example from a k-means run.
2. E-step: compute each point's responsibility for each component.
3. M-step: re-estimate each component's mean, covariance and weight using responsibilities as soft counts.
4. Repeat until the log-likelihood stops improving; EM never decreases it.
```

## Principal component analysis
summary: Projecting data onto the orthogonal directions of greatest variance.
prereq: Mathematical foundations > Linear algebra

```definition
Principal component analysis (PCA) finds new axes, the principal components, that are orthogonal and ordered by how much of the data's variance they capture. Keeping the first few components compresses the data while losing as little variance as possible.
```

```formula
name: Covariance matrix and principal directions
latex: S = \frac{1}{n}\sum_{i=1}^{n} (\mathbf{x}_i - \bar{\mathbf{x}})(\mathbf{x}_i - \bar{\mathbf{x}})^{\top}, \qquad S\mathbf{u}_j = \lambda_j \mathbf{u}_j
text: The principal components are the eigenvectors of the covariance matrix, and each eigenvalue is the variance along its component.
```

```formula
name: Explained variance ratio
latex: \frac{\sum_{j=1}^{k} \lambda_j}{\sum_{j=1}^{d} \lambda_j}
text: The share of total variance kept by the first k components; a common rule is to keep enough components for 90 to 95 percent.
```

```steps
title: Computing PCA
1. Centre the data by subtracting the mean of each feature, and standardise if features use different units.
2. Compute the singular value decomposition of the centred data matrix (or the eigenvectors of its covariance).
3. Sort the components by singular value or eigenvalue.
4. Project the data onto the top k components to get the reduced representation.
```

```pitfall
PCA only finds linear structure and is driven by scale: an unstandardised feature measured in large units will dominate the first component.
```

## Non-linear embeddings
summary: t-SNE and UMAP for visualising high-dimensional data in two or three dimensions.

```definition
t-SNE and UMAP map high-dimensional points to two or three dimensions so that points that were neighbours stay neighbours. t-SNE matches neighbour probabilities by minimising a KL divergence; UMAP builds a fuzzy neighbour graph and optimises a similar layout faster.
```

```pitfall
Distances between clusters and the size of clusters in a t-SNE or UMAP plot are not meaningful, and results change with the perplexity or neighbour settings. Use them to look at data, not as features for measurement.
```

## Anomaly detection
summary: Finding rare examples that do not fit the normal pattern.

```definition
Anomaly detection flags examples that are unlikely under a model of normal data. Approaches include density thresholds (an example with p(x) below epsilon is anomalous), distance to neighbours, isolation forests that isolate outliers with few random splits, and reconstruction error from an autoencoder.
```

```application
Credit-card fraud, machine-fault monitoring, network intrusion detection and quality control on production lines.
```
