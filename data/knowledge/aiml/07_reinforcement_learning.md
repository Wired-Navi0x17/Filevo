# Reinforcement learning
summary: Learning to act by trial and error from rewards, with value-based, policy-based and actor-critic methods.
prereq: Mathematical foundations > Probability and statistics

```definition
In reinforcement learning (RL) an agent interacts with an environment over time. At each step it observes a state, takes an action, and receives a reward and the next state. Its goal is a policy, a rule for choosing actions, that maximises the total reward it collects in the long run. Nobody tells the agent the right action; it learns from the consequences of its own choices.
```

```compare
caption: How reinforcement learning differs from supervised learning
Aspect, Supervised learning, Reinforcement learning
Feedback, correct label for each example, a scalar reward that may be delayed
Data, fixed data set, generated by the agent's own actions
Goal, predict well, act to maximise cumulative reward
Main difficulty, generalisation, exploration and credit assignment
```

## Markov decision processes
summary: The formal model of an RL problem: states, actions, transitions, rewards and discounting.

```definition
A Markov decision process (MDP) is a tuple (S, A, P, R, gamma): a set of states, a set of actions, transition probabilities P(s' | s, a), a reward function R(s, a), and a discount factor gamma between 0 and 1. The Markov property says the next state depends only on the current state and action, not on the earlier history.
```

```formula
name: Discounted return
latex: G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^{k} r_{t+k+1}
text: The total future reward, where rewards further away count less; gamma near 0 makes the agent short-sighted and gamma near 1 far-sighted.
```

```formula
name: State-value and action-value functions
latex: V^{\pi}(s) = \mathbb{E}_{\pi}[G_t \mid s_t = s], \qquad Q^{\pi}(s, a) = \mathbb{E}_{\pi}[G_t \mid s_t = s, a_t = a]
text: V says how good it is to be in a state when following policy pi; Q says how good it is to take action a there and follow pi afterwards.
```

## Bellman equations
summary: The recursive relationships that value functions satisfy.
prereq: Reinforcement learning > Markov decision processes

```formula
name: Bellman expectation equation
latex: V^{\pi}(s) = \sum_{a} \pi(a \mid s) \sum_{s'} P(s' \mid s, a)\big[ R(s, a, s') + \gamma V^{\pi}(s') \big]
text: The value of a state is the expected immediate reward plus the discounted value of where you land, averaged over the policy and the environment.
```

```formula
name: Bellman optimality equation
latex: V^{*}(s) = \max_{a} \sum_{s'} P(s' \mid s, a)\big[ R(s, a, s') + \gamma V^{*}(s') \big], \qquad Q^{*}(s, a) = \sum_{s'} P(s' \mid s, a)\big[ R + \gamma \max_{a'} Q^{*}(s', a') \big]
text: The optimal value picks the best action at every step; acting greedily with respect to Q* gives an optimal policy.
```

## Dynamic programming
summary: Policy iteration and value iteration, which solve an MDP when its model is known.
prereq: Reinforcement learning > Bellman equations

```steps
title: Value iteration
1. Initialise V(s) = 0 for every state.
2. For every state, set V(s) to the maximum over actions of the expected reward plus gamma times the value of the next state.
3. Repeat the sweep until the largest change in any V(s) is below a small threshold.
4. Extract the policy by choosing, in each state, the action that achieves that maximum.
```

```steps
title: Policy iteration
1. Start with any policy.
2. Policy evaluation: solve the Bellman expectation equation for that policy's values.
3. Policy improvement: make the policy greedy with respect to those values.
4. Repeat until the policy no longer changes; it is then optimal.
```

```pitfall
Dynamic programming needs the full transition model and sweeps over every state, so it does not scale to huge or unknown environments. Model-free methods learn from sampled experience instead.
```

## Monte Carlo and temporal-difference learning
summary: Learning values from experience, by full returns (Monte Carlo) or by bootstrapping from estimates (TD).
prereq: Reinforcement learning > Bellman equations

```formula
name: Monte Carlo update
latex: V(s_t) \leftarrow V(s_t) + \alpha\big[ G_t - V(s_t) \big]
text: After an episode ends, move the estimate towards the actual return that followed the state.
```

```formula
name: TD(0) update
latex: V(s_t) \leftarrow V(s_t) + \alpha\big[ r_{t+1} + \gamma V(s_{t+1}) - V(s_t) \big]
text: Update after a single step towards the reward plus the estimated value of the next state; the bracket is the TD error delta.
```

```compare
caption: Monte Carlo versus temporal-difference learning
Aspect, Monte Carlo, Temporal difference
Waits for, the end of the episode, one step
Target, actual return G_t, r + gamma V(s')
Bias, unbiased, biased by the current estimate
Variance, high, lower
Works without episodes ending, no, yes
```

## Q-learning and SARSA
summary: Model-free control methods that learn action values directly.
prereq: Reinforcement learning > Monte Carlo and temporal-difference learning

```formula
name: Q-learning update
latex: Q(s, a) \leftarrow Q(s, a) + \alpha\big[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \big]
text: Off-policy: the target uses the best next action, so Q-learning learns the optimal policy even while it explores.
```

```formula
name: SARSA update
latex: Q(s, a) \leftarrow Q(s, a) + \alpha\big[ r + \gamma Q(s', a') - Q(s, a) \big]
text: On-policy: the target uses the action a' the agent actually takes next, so SARSA learns the value of the policy it is following, exploration included.
```

```steps
title: Tabular Q-learning with epsilon-greedy exploration
1. Initialise Q(s, a) arbitrarily, for example to zero.
2. In state s, choose a random action with probability epsilon, otherwise the action with the highest Q(s, a).
3. Take the action and observe the reward r and the next state s'.
4. Update Q(s, a) towards r + gamma times the maximum Q(s', a').
5. Set s to s' and repeat; decay epsilon over time.
```

```example
In the cliff-walking grid, SARSA learns a safe path away from the cliff edge because its exploratory steps sometimes fall off, while Q-learning learns the shorter path along the edge, which is optimal when there is no exploration.
```

```definition
Deep Q-networks (DQN) replace the Q table with a neural network and add two stabilisers: an experience replay buffer that samples past transitions at random, and a separate target network that is updated slowly. DQN learned to play Atari games from pixels (Mnih et al., 2015).
```

## Exploration versus exploitation
summary: Balancing trying new actions against using what is already known.

```definition
An agent must exploit actions it already knows are good, but also explore others that might be better. The multi-armed bandit is the simplest form of the problem: several slot machines with unknown payouts and no states.
```

```formula
name: Upper confidence bound (UCB1)
latex: a_t = \arg\max_{a} \left[ \hat{Q}(a) + c \sqrt{\frac{\ln t}{N(a)}} \right]
text: Choose the action whose estimated value plus an uncertainty bonus is highest; rarely tried actions get a large bonus.
```

```compare
caption: Exploration strategies
Strategy, Idea, Notes
Epsilon-greedy, random action with probability epsilon, simple; often epsilon is decayed
Softmax (Boltzmann), sample actions in proportion to exp(Q / T), temperature T controls randomness
UCB, optimism under uncertainty, strong guarantees for bandits
Thompson sampling, sample from the posterior and act greedily, Bayesian and very effective in practice
Entropy bonus, reward the policy for staying random, used with policy gradients
```

## Policy gradient methods
summary: Optimising a parameterised policy directly by gradient ascent on expected return, including REINFORCE with a baseline.
prereq: Reinforcement learning > Markov decision processes
prereq: Mathematical foundations > Calculus and gradients

```definition
Policy gradient methods represent the policy itself as a differentiable function pi_theta(a | s), for example a softmax over action scores, and adjust theta in the direction that increases the expected return. They handle continuous and stochastic actions naturally and can learn stochastic policies.
```

```formula
name: Policy gradient theorem
latex: \nabla_{\theta} J(\theta) = \mathbb{E}_{\pi_{\theta}}\big[ \nabla_{\theta} \log \pi_{\theta}(a_t \mid s_t) \, G_t \big]
text: The gradient of expected return is the expected score function times the return: make actions that led to high return more likely.
```

```formula
name: REINFORCE with a baseline
latex: \theta \leftarrow \theta + \alpha \, \big(G_t - b(s_t)\big) \, \nabla_{\theta} \log \pi_{\theta}(a_t \mid s_t)
text: Subtracting a baseline b, such as a running average of returns, does not change the expected gradient but greatly lowers its variance. The term G_t minus b is the advantage.
```

```formula
name: Softmax policy gradient
latex: \frac{\partial \log \pi_{\theta}(a \mid s)}{\partial \theta_{k}} = \mathbb{1}[k = a] - \pi_{\theta}(k \mid s)
text: For a softmax over action logits, the chosen action's logit goes up by one minus its probability and every other logit goes down by its probability.
```

```steps
title: REINFORCE
1. Initialise the policy parameters theta and the baseline b.
2. Run the policy to collect an episode of states, actions and rewards.
3. For each step compute the return G_t from that step onwards.
4. Update theta by alpha times (G_t minus b) times the gradient of log pi(a_t | s_t).
5. Update the baseline, for example b becomes 0.9 b plus 0.1 G.
6. Repeat for many episodes.
```

```pitfall
Plain REINFORCE has very high variance because one episode's return is a noisy signal. Baselines, larger batches, an entropy bonus and actor-critic methods are the standard remedies.
```

## Actor-critic methods
summary: Combining a learned policy (actor) with a learned value function (critic).
prereq: Reinforcement learning > Policy gradient methods
prereq: Reinforcement learning > Monte Carlo and temporal-difference learning

```definition
An actor-critic method keeps two models. The actor is the policy and chooses actions. The critic estimates values and tells the actor how much better or worse an action was than expected, using the TD error as the advantage instead of a full Monte Carlo return.
```

```formula
name: Advantage actor-critic update
latex: \delta_t = r_{t+1} + \gamma V_{w}(s_{t+1}) - V_{w}(s_t), \qquad \theta \leftarrow \theta + \alpha_{\theta}\, \delta_t \nabla_{\theta}\log \pi_{\theta}(a_t \mid s_t), \qquad w \leftarrow w + \alpha_{w}\, \delta_t \nabla_{w} V_{w}(s_t)
text: The critic's TD error delta is both the critic's learning signal and the actor's advantage estimate.
```

```compare
caption: Families of reinforcement learning algorithms
Family, Learns, Examples, Strength
Value-based, Q(s a), Q-learning and DQN, sample-efficient for discrete actions
Policy-based, pi(a | s), REINFORCE, simple and handles continuous actions
Actor-critic, both, A2C and PPO and SAC, lower variance and stable at scale
Model-based, a model of P and R, Dyna and MuZero, plans ahead and needs fewer real samples
```

```application
Game playing (AlphaGo, Atari), robot control, recommendation and ad placement, resource scheduling, and fine-tuning language models from human feedback (RLHF, which uses PPO).
```
